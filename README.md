# 📊 Human Resources Dashboard (Tableau)

An interactive Tableau dashboard developed to analyze employee demographics, hiring trends, department performance, salary insights, and workforce analytics.

The dashboard provides HR-focused business insights through interactive visualizations and filters.

---

# 🚀 Project Highlights

- Fully interactive Tableau dashboard
- Employee demographics analysis
- Department-wise employee tracking
- Salary and age analysis
- Education and performance insights
- Hiring and termination trends
- Geographic employee distribution

# 📊 Dashboard Features

### 🏠 HR Overview
Employee KPIs, active employees, hiring and termination analysis

### 👥 Demographics Analysis
Gender distribution, age groups, education levels, and performance analysis

### 💰 Salary Insights
Salary comparison by age, education, and gender

### 🌍 Geographic Analysis
Employee distribution by location and branch analysis
